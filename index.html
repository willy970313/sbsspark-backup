Personal backup utility

Personal file backups.

sbsspark-backup maintains backup copies of the account owner's files in Google Drive.

Purpose

The account owner operates this utility for personal backup and recovery. It uploads new and changed files and retains earlier versions according to its backup settings.

Google Drive access

The utility requests the drive.file permission to create and manage its backup files and folders. The owner grants access through Google's authorization screen.

Data handling

Backup data passes directly between the owner's device and Google Drive. Authorization information is stored on the owner's device.

The privacy policy describes the data handled by the utility, retention, and how the owner can revoke access.
